# DFL Frictionless Sandbox Repo (`examples/demo-repo`)

This pre-initialized repository lets you inspect a real **dfl (devFlow)** project (`dev` flow, 6 steps, 4 routes) in under 30 seconds without touching your own production repository or committing `.df/` to `main`.

## What's Inside

- `.df/` — Genuine `dev` flow generated by `dfl install --yes --agents claude,cursor` (`flow.json`, Handlebars step templates, and partials)
- `.mcp.json` & `.cursor/mcp.json` — Ready-to-use stdio MCP server configs for Claude Code and Cursor
- `docs/requirements/checkout/REQUIREMENTS.md` — Documentation-only Gherkin (`Given/When/Then`) with stable IDs (`CHK-1.1`, `CHK-1.2`)
- `src/checkout/discount.mjs` & `test/discount.test.mjs` — Minimal Node.js module and `node:test` suite citing `CHK-1.1` / `CHK-1.2`

## Run the 1-Command Sandbox

From the repository root (requires **Node.js `>=22.12`**):

```bash
# Non-interactive print mode (runs dfl status + dfl flow view --print --zoom 1)
./demo/run-demo.sh --print

# Pure ASCII DAG output
./demo/run-demo.sh --print --ascii

# Interactive full-screen Ink + ELKjs terminal DAG viewer (TTY)
./demo/run-demo.sh --interactive
```

The launcher copies this directory into a temporary workspace and cleans it up automatically on exit, leaving your working tree completely untouched.
